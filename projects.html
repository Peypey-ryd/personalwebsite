Equity-First Managed Retreat Simulator

🥇 1st place — WMGIC × PIT-UN 2026, William & Mary · Python, Flask, JavaScript

A participatory budgeting tool for coastal climate adaptation in Miami-Dade. Managed retreat decisions are usually made top-down, which tends to favor wealthy real estate over vulnerable neighborhoods — this puts the choices in the community's hands instead. Users allocate a budget across infrastructure, soft interventions, and relocation programs, then see the projected equity outcomes for each neighborhood. Built on a Flask API for outcome modeling, with Leaflet and OpenStreetMap rendering GeoJSON census tracts layered with flood-risk and demographic data, and Chart.js for the equity charts. Deployed on Render.

JackHackDay — data-driven policy suggestions

🥇 1st place, data-driven policy track — GUWeCode Gemini API × MLH hackathon · Python, JavaScript

A tool that turns a dataset into evidence-based policy recommendations instead of relying on intuition. It pairs Google's Gemini API with analysis of a California dataset to generate and rank policy suggestions, wrapped in a browser interface. Python handles the data processing and Gemini calls; HTML, CSS, and JavaScript make up the front end. Built for GUWeCode and Hoya Hacks.
