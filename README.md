# Personal Website

Simple static personal website scaffold. Open `index.html` in a browser to view.

Quick start:

```bash
# from the project folder
start index.html   # on Windows
# or
open index.html    # macOS
# or
xdg-open index.html # Linux
```

You can also serve it with a static server, e.g.:

```bash
# using Python 3
python -m http.server 8000
# then visit http://localhost:8000
```
